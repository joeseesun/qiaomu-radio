# 立体收音机功能与建模契约

生成前确定：

| 部件 | 正常收听 | 菜单模式 | BANG 分件目标 |
|---|---|---|---|
| 右上玻璃屏 | 第一行电台名，第二行歌名，第三行歌手与状态；无曲目时显示地区/标签 | 点击打开可读的频道、搜索、收藏、历史页面 | 屏幕/玻璃独立，平整无烘焙文字 |
| 大银色旋钮 | 转动选择下一家/上一家，按下确认 | 选台 | 独立旋钮，旋转轴垂直面板 |
| 小炭黑旋钮 | 拖动/滚轮调节音量，按下静音或恢复 | 音量持续可用 | 独立旋钮 |
| 橙色按钮 | 播放/暂停 | 播放/暂停 | 独立可按压按钮 |
| 扬声器/外壳 | 完整机身、实体材质 | 不遮挡页面 | 分离以支持可选拆解展示 |

Rams 实时屏幕使用 CSS3D 将可访问 DOM 固定到玻璃表面，不把中文、歌名或状态烘焙进模型。文字随电台更新；长标题分行/截断。点击屏幕靠近机内菜单，支持中文输入法搜索；不是独立网页弹层。

曲目来源：第一期仅接入可验证的 SomaFM 官方 songs JSON。没有实时数据时显示电台名与直播信息，不制造歌名、歌手、封面和曲目时长。直播不显示可拖动的歌曲进度条。曲目数据可能相对音频存在 CDN 延迟。

验收：正面、侧面、近景查看；控制件命中实际网格；旋钮行为改变播放器状态；暂停停止音频；主题切换只显示一枚入口图标；BANG 拆解可收回；键盘/触屏有可访问的操作入口。

## 实际交付与边界（2026-09-13）

- 内置 imagegen 参考图：`docs/assets/radio-reference.png`；设计过程图也归档在 `docs/assets/`，不会复制进生产构建。
- Hyper3D 原始模型：`c09b58d5-1858-496e-b037-00c04f9813e3`，本地归档 `artifacts/models/radio-base.glb`。
- 早期 BANG：`13b6148c-9644-49fe-a33e-a9367df2acdf`，历史资产 `artifacts/models/radio-parts.glb`，约 15 MB；当前 Rams 不再请求该文件，也不会复制进生产构建。
- 当前 Rams 完全由 `src/radioModel.ts` 同步构建：机壳、前后盖、脚垫、螺钉、网孔、固定音量刻度与全部控制件均为参数化几何。前盖搭接机壳、网板齐平，不再暴露黑色垫层。屏幕坐标与地面高度由共享常量约束；拆解是外观部件装配展示，不是电子内部结构仿真。
- High 拆件请求被服务拒绝；Basic 请求成功。实际 5 个组件，不是预期的 7 个：`root.0` 音量、`root.1` 屏幕、`root.2` 调谐、`root.3` 外壳/扬声器/脚座、`root.4` 播放键。扬声器与脚座未独立拆出。拆解是交互概念展示，不代表真实电子内部结构。
- 屏幕与控制按 BANG 顶点边界校准。Rams 的大小旋钮、橙色播放键统一替换为 128 段参数化 LatheGeometry，含连续圆角和独立底座圈，保留真实轴心；屏幕与边框使用规整圆角几何，消除生成模型的碎面。扬声器替换为 33×29 规则孔板，含实际孔壁与深色背板。原模型文件未覆盖。没有调用 Blender。
- 1440×900 与 390×844 浏览器视口已查看；后者是响应式模拟，不是真机。已验证播放键、屏幕菜单、旋转即时换台与按下播放/暂停、搜索返回、SomaFM 真实曲目、近景/侧面/拆解。
- 参数化版本 `npm run check`：24 个测试通过，包含部件命名、音量与调谐、几何尺寸与法线、脚垫落地、屏幕坐标、正面/两侧控制件命中、拆解部件登记。TypeScript 与生产构建通过，仍提示 HLS/Three.js 模块较大。未发布到公网。
- 实测：1440×900、390×844 无横向溢出；拖音量、按下静音/恢复、调谐即时播放、机内搜索与真实曲目、侧面旋钮轮廓、规则网孔。双指缩放已实现但未在物理手机验证。默认无底部播放器，恢复视角和拆解均在机内菜单；模型失败时直接降级到屏幕播放器。魔兽世界 3D 主题保持独立实现。

## 物理操作修订验收（2026-09-13）

- 音量刻度：270° 固定弧、13 根刻线、加长端点与 −/+，指针独立转动。静音不改变物理角度。
- 调谐使用旋钮所在平面的角度增量，支持跨 ±π 与连续多圈；每圈 20 档，松手归档，按下确认。音量到头截断，反向无空行程。
- 565×828 浏览器复验：博朗默认为轻微右上方透视；拖动大旋钮从 Soundstorm 立即切到 Monte Carlo 并连接，按下大旋钮可播放/暂停。机内菜单左上角为恢复原始视角图标。
- 横向大角度翻至后盖、纵向竖起机身均实测；后向屏幕从画面与可访问树隐藏。首轮发现竖起超出画面，已加检查视角最小距离并复测完整显示。
- 390×844 浏览器视口检查完整正面与机内菜单；不是物理手机，双指与连续圆周触摸仍需真机体验。
- `npm run check`：28 项测试、TypeScript 与生产构建通过。新增连续两圈 40 档、双向止挡、到头反向、刻度独立、面板与网板齐平测试。仍有原有大包警告，未发布公网。

## 魔兽世界 3D 修订（2026-09-13）

- 原问题：文本面与反馈层使用整个模型的 `max.z`（约 0.479），而黑玻璃位于约 0.235；角度变化时形成明显悬空。菜单另用页面定位弹层，和模型不在同一坐标系。
- 改为实际网格表面采样；黑玻璃保留圆角和边框内缩，模型全局包围盒不再用作屏幕定位。菜单与显示面共享几何标定，CSS3D 保留搜索、滚动与键盘访问。
- 五个按钮命中最近真实网格；前部顶点压入与回弹，贴面短亮反馈；音量前部顶点和原始纹理随拖拧转动。原始 GLB 文件未改写，也未新增 BANG/Blender 请求。
- 两轮验收：发现圆角处矩形面碰边框、搜索页继承列表滚动，分别通过圆角内缩与切页复位修正。
- 浏览器 1280×720：前面/斜侧面贴合、播放、切台、收藏/取消收藏、音量调到 100% 后反向降至 83%、静音恢复、机内 SomaFM 搜索与选台通过；390×844 检查完整机身和机内搜索结果。移动尺寸模拟不等同真机。
- 31 项测试、TypeScript 和生产构建通过；新增基于真实 GLB 的玻璃表面偏移、控件深度、背面拒绝命中、顶点按压/旋转及恢复测试。原有 HLS/Three.js 大包警告仍在，未发布公网。
- 生产模型 v2 保留 2048×2048 纹理、浮点几何与全部 53,655 个顶点，仅把内嵌 PNG 转为 WebP 传输格式；文件由 12.25 MB 降至约 2.74 MB。原模型仍可从 Git 历史恢复。
